# Digest Entry Template

Use this format for every research input. One entry per story. 3–5 entries per session max.

---

## Template

```
Title: [headline or your own summary of what the story is actually about]
Source: [URL — direct link to the article, paper, or thread]
Summary: [2–3 sentences: what it says and why it matters right now]
Angle: [1 sentence: the content hook this becomes — lead with the tension or insight]
Quote: [optional — one verbatim line worth using, in quotes, if it's strong enough to anchor a post]
```

---

## Example Entries

```
Title: Mistral releases Le Chat with native code execution
Source: https://mistral.ai/news/le-chat-code-execution
Summary: Mistral's consumer chat app now runs Python in-browser with no sandboxing lag. This closes the feature gap with ChatGPT's code interpreter and positions Le Chat as a serious alternative for developers who want a lightweight option. No API key needed for basic use.
Angle: The quiet open-source move that's outpacing the closed-source labs — and why speed-of-shipping matters more than model size in 2026.
```

```
Title: GitHub Trending: uv hits 30k stars — Python packaging finally solved?
Source: https://github.com/astral-sh/uv
Summary: uv, the Rust-based Python package manager from Astral, crossed 30k GitHub stars this week. It's 10–100x faster than pip and handles virtualenvs automatically. The developer tooling community is calling it a step-change, not just an improvement.
Angle: Every programming community eventually gets the tool that obsoletes everything before it. Python's moment might finally be here.
```

---

## Quality Check Before Saving

- [ ] Source URL works and links directly to the story
- [ ] Summary is written in my voice — not copied from the article
- [ ] Angle is a single sentence with a clear hook (not a description of the story)
- [ ] This story is fresh — published within the last 48 hours unless it's a slow-burn trend
